# Linkovi za sekvencijalnu implementaciju

- [IVFFlat (Inverted File Flat) Index – Vector Database from Scratch](https://skyzh.github.io/vector-db-from-scratch/cpp-05-ivfflat): objašnjenje IVFFlat indeksa, pseudokod k-meansa i implementacija u C++-u.
- [How to Build IVF Index](https://oneuptime.com/blog/post/2026-01-30-ivf-index/view): Python tutorijal (NumPy) od nule: k-means, invertovane liste i pretraga sa podesivim brojem listi, uz primjer sa FAISS-om.
- [FAISS repozitorij](https://github.com/facebookresearch/faiss): izvorni kod biblioteke sa kojom poredimo rezultate (`IndexIVFFlat`).
